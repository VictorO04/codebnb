## Requisitos

### 1.1 Requisitos Funcionais do Sistema

| ID | Requisito | Descrição |
| --- | --- | --- |
| RF01 | Realizar Login | O usuário deve ser capaz  |
| RF02 | Exibir Tela Principal | Deve permitir que o usuário visualize o conteúdo do site |
| RF03 | Cadastrar | Usuários devem ser capazes de se cadastrarem no site |
| RF04 | Consultar | O usuário deve ser capaz de consultar dados de clientes, imóveis e alugueis |
| RF05 | Atualizar | O usuário deve ser capaz de atualizar cadastros já criadas |
| RF06 | Excluir | O usuário deve ser capaz de excluir dados já criados |
| RF07 | Encerrar Login | O usuário deve ser capaz de fazer logout |

### 1.2 Requisitos Não Funcionais

| ID | Requisito | Descrição |
| --- | --- | --- |
| RNF01 | Proteção de Dados | O usuário deve se sentir seguro |
| RNF02 | Integridade dos Dados | Os dados não devem ser vazada |
| RNF03 | Controle de Acesso | Apenas usuários específicos devem ter acesso a áreas específicas |
